# 從這裡開始——從零到一台自己會飛的無人機

## 目標，一句話

**教會一台 27 克的無人機自己飛——相機進、決策出——完全離線，跑在一顆只有
512 KB 記憶體的晶片上。**

這門課的每一課都在為這句話服務。你會從物理模擬器出發（免費、在你的 Mac 上）、
教一個小小的神經網路「看見」與「決定」，並且讓一切保持夠小、夠誠實——小到能跑在
無人機自己身上：不靠筆電、不靠 Wi-Fi、不靠雲端。真機是可選的最後一步，不是入場費。

## 你需要什麼

- 一台 Apple Silicon 的 Mac（M1 以上）。就這樣——**$0**。
- 不需要機器人或機器學習背景。每一課都先講*為什麼*再講*怎麼做*，
  看不懂的詞都在[術語表](GLOSSARY.md)裡用白話解釋。

## 你的第一次飛行（15 分鐘）

```bash
git clone https://github.com/csinghans/nanodrone-ai.git
cd nanodrone-ai
bash setup/install_env.sh          # 一次性：conda 環境 + 模擬器
conda activate nanodrone-ai
python lessons/01_hover/hover_demo.py
```

視窗打開，一台小四軸機起飛、穩穩懸停在 1 公尺，終端機印出一行 `HOVER OK` 開頭
的字。這行字是這門課的習慣：**每一課的結尾都有一個電腦替你驗證的檢查點**——
`OK` 那行印得出來，就代表你做對了。

## 地圖

第 1–10 課請按順序走——每一課都建立在上一課之上。之後就跟著好奇心走：
每課 README 的開頭都有一行摘要和「建立在哪幾課之上」的提示，你永遠知道
該先讀什麼。

| 階段 | 課次 | 白話說明 |
|---|---|---|
| **會飛、會看、會決定** | 1–10 | 懸停、用相機找東西、學會第一個行為、用手把和語音控制——打地基。 |
| **任務** | 11–16 | 把單一技能組成有安全機制的完整任務，收在一個由你設計、有評分表的 capstone。 |
| **上晶片** | 14b、17–22 | 單相機測深度、光流、用強化學習閃障礙——每一項都壓進小到能跑在無人機晶片上的模型。 |
| **前沿** | 23–30 | 飛行黑盒子、$100 真機踏腳石、所有無人機共用的一份指令協議、一個在障礙靠近*之前*就閃開的 nano 世界模型——以及課程總結。 |
| **支線** | DroneVoice | 一個用講話就能飛無人機的 iPhone app，說的是同一份指令合約。 |

有兩條規則貫穿整門課，你會在每一課遇到它們：

1. **兩層架構**——你的 AI 永遠不直接驅動馬達。它只送簡單指令（「以 0.8 m/s 前進」），
   由久經考驗的飛控保住飛機。真正的自主無人機就是這樣蓋的。
2. **量測，而非宣稱**——模擬器免費把訓練標籤交給你、你訓練自己的小模型，
   而每個結果都是一行你隨時能重跑驗證的數字。
